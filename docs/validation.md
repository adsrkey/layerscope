# Что проверено и чему можно верить

Сверка с настоящей моделью сделана на **Qwen3.8-27B, 4 бита** (`mlx-vlm` 0.7.12, `mlx` 0.32.4). Крошечная случайная модель из `tests/tiny.py` проверяет математику, но не поведение настоящей.

## Проверено напрямую

| Что | Как проверено | Результат |
|---|---|---|
| Разложение логита (DLA) | сумма вкладов компонент против настоящего логита | 25,486 против 25,500 (27B); для всех пяти кандидатов — тест на крошечной модели. Расхождение 0,6% — половинная точность |
| Энтропия шага | топ-20 плюс хвост против полной энтропии, `exp(H)`, биты | сходится (тест) |
| Веса внимания | восстановленные из запросов и ключей веса, умноженные на значения, против выхода настоящего внимания | ошибка около 1,3% на промпте и 0,3% при декодировании на 27B (округление bf16); тест на крошечной модели |
| Отключение слоя | равно вычитанию записей слоя из потока; модель после прогона не меняется | тест |
| Патчинг | подмена последнего слоя на последней позиции возвращает чистый ответ | тест; на 27B картина осмысленная |
| Вклад токенов (подмена) | пакетная подмена против подмены по одному | совпадает (тест); на промпте про Францию выделяет «Франции», «столиц», «словом» |

## Приближения по построению

- **Logit lens в ранних слоях** неточен: векторы ещё не в базисе последнего слоя. Колонка «KL до итога» показывает размер ошибки; точнее tuned lens (на 27B не запускался).
- **Подмена токена** зависит от «нейтральной» замены (средний эмбеддинг контекста); токены могут влиять вместе, и замена одного не покажет эффекта, если соседний его дублирует.
- **Отключение слоя** заменяет выход слоя его входом. Для слоя 0 это выход за распределение (KL 12,4 на 27B), так что его важность несопоставима с остальными. Важность верна только для набора промптов, на котором считалась; интервалы бутстрепа считают промпты независимыми.
- **Угловое расстояние** усреднено по всем позициям, кроме первой, и по промптам. Оно указывает кандидата на удаление блока, но не заменяет проверку и дообучение.

## Что проверка показала плохим — и убрано

| Метод | Сверка на 27B | Что сделано |
|---|---|---|
| gradient × input, integrated gradients (вклад токенов) | против подмены токена: ранговая корреляция около 0,1, знак совпадает не чаще случайного; выделяли служебные токены шаблона вместо слов промпта | заменены подменой; код лежит в `layerscope/experimental.py` |
| attribution patching (важность слоёв по градиенту) | корреляция с перебором 0,12 по Пирсону и 0,35 по рангам | убрано из карты и отчёта; код в `experimental.py` |
| эвристика «особенно важный слой» в сводке | пороги выбраны вручную, без статистики | убрана |

## Не проверялось

- tuned lens и сравнение квантизаций на настоящей паре моделей;
- совпадает ли шаблон чата и токенизация с тем, что строят LM Studio и oMLX (отчёт показывает, какая строка ушла в модель);
- вид страниц отчёта в браузере: скрипт страницы выполняется в Node с заглушкой DOM (`tests/check_report.js`), расположение, подписи осей и подсказки глазами не смотрелись;
- модели других архитектур: проект привязан к `qwen3_5` в `mlx-vlm`.
